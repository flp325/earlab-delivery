# EarLab 0.6.1 重构与验收记录

本轮基于 `96068d2`（功能基线 `v0.6.1 / c5ac653`），开发分支 `codex/earlab-refactor`。
六页导航、10 题训练、12 题测评、阶梯/Elo/JND、A/B 等响、VST3 题型、CSV/HTML 导出和既有 JSON 格式保持兼容。
版本仍为 0.6.1；新增独立目录中的重构预览包，不覆盖原发布文件，不视为正式发布。

## 架构调整

- `MainComponent.cpp` 保留会话与应用协调；页面布局移入 `MainComponentLayout.cpp`，插件流程移入 `MainComponentPlugin.cpp`，共享显示辅助函数集中在 `MainComponentSupport.h`。
- `LatestSnapshot<T>` 用三页的独占所有权交换替代 EQ 循环索引。一个写者和一个读者；读者持有页面期间不会被生产者覆盖，无锁、无分配、无重试，不再依赖 60 Hz 发布上限。
- `PluginLoadJob` 仅持有扫描／预检元数据，worker 不访问 UI 或音频引擎；消息线程轮询完成结果。取消／析构请求停止并回收隔离子进程，禁止同进程扫描回退。
- `HistoryPagination` 是独立纯逻辑模型，覆盖翻页边界、空数据及缩放时的记录位置；原有历史行高、表头、页脚、内容列宽保持。

## 修复与优化

1. 压缩器 `prepare()` 重算 attack/release 系数，切换设备采样率后时间常数正确。
2. 非循环素材播放到结尾后输出静音，不再无限重复最后一个样本；render 按连续区间批量复制，并限制输出长度。
3. 素材解码先检查读取结果，重采样到临时缓冲后再提交；校验异常采样率、噪声长度和输出样本数量。
4. EQ 拒绝非法／非有限参数导致的失稳；频响预览使用请求的采样率限制 Nyquist。
5. EQ 频响系数每次预览只生成一份，供 180 个绘图点复用；中性压缩器在无释放尾音时使用整块增益快路。
6. 原 `moveFileTo` 会先删除目标，不能提供真正原子替换。改用独立临时文件与 `replaceFileIn`；备份也先写临时文件再替换，失败时停止保存，绝不退回复制覆盖主文件。
7. 训练、测评与插件记忆的结构损坏不再被误认作空档案；主文件缺失时也尝试 `.bak`，恢复后的首次保存保留好备份。
8. 切换档案前清理插件目录和记忆，避免坏档沿用上一档案的内存数据；插件题成功挂载后才记入记忆，保存失败有可见提示。
9. 插件预热产生非有限音频时拒绝加载。扫描／预检移出消息线程，显示进度和取消入口；CLI 自动开训等待加载完成。
10. 延迟 QA 回调和启动回调使用 `SafePointer`；会话代次避免旧轮次的延迟动作推进新轮次。插件库／音频设置窗口随主窗口释放，避免悬空引用。
11. 历史表提供上一页／下一页、滚轮、Page Up/Down、Home/End，200 条记录均可访问。
12. 状态胶囊长文本显示省略号并提供完整 tooltip；能力条给增量徽章预留空间；设置、素材和首页辅助文案采用既有字体 token，提高可读性。
13. 应用、设置和状态版本号统一由 CMake/JUCE 版本宏提供。

## 构建与测试

- `scripts/build.ps1` 默认运行 CTest 三组门禁，再做 trim 自检和本地签名。
- `EarLabPluginTests --unit-only` 是确定性插件回归，不依赖安装的插件或扫描缓存。默认无参数、`--rescan`、`--file=` 原有诊断功能保留。
- `verify-toolchain.ps1` 优先使用仓库内 CMake，检查 NMake，不再因缺少可选 Ninja 报错。
- 新增回归先在旧实现上复现：`artifacts/refactor-red-engine.log`（5 项失败）、`refactor-storage-red-engine.log`（5 项失败）、`refactor-storage-red-plugin.log`（3 项失败）。
- 新增快照持有／并发 50,000 次发布、历史分页、真实子进程取消回收测试。
- `scripts/benchmark.ps1` 从 `v0.6.1` 提取临时源码并重命名类，在同一个 Release 进程中比较原实现与当前实现；每项预热后取 5 次中位数。目标仅按需构建，不加入普通门禁。

## 保留的边界与未完成项

- 异步化覆盖扫描和隔离预检；正式 VST3 实例化仍在消息线程执行，以兼容依赖消息线程的插件。首次实例化和离线出题仍可能耗时，不能宣称任意第三方插件都不会阻塞或崩溃。
- 单元测试、单个真实插件和自动答题验证不等同于全面插件兼容性或主观听感校准。
- 安装器与许可策略保持；已生成预览 setup，未正式发布。修正版的清洁机验收结果见上表。
- 依赖下载脚本的校验加固、全应用架构进一步拆分、彻底隔离插件实时处理、硬件性能跨机测量未包含在本轮。
