What the corresponding source contains
--------------------------------------
- app/            C++20 source of the EarLab engine and UI, CMake build files
- scripts/        build, signing, packaging and verification scripts
- installer/      Inno Setup script, license and third-party notice files
- docs/, PRD, tests
- instructions for fetching the exact JUCE 8.0.15 source tree
  (scripts/fetch_juce.py, https://github.com/juce-framework/JUCE/tree/8.0.15)

Where to obtain it
------------------
- A source archive (earlab-0.6.1-source.zip) is published next to this
  installer when the distributor publishes the binary release.
- If it is not available there, request it from the EarLab maintainers
  through the same channel that delivered this build. Include the build
  revision shown in BUILD-INFO.txt, which is distributed with the
  installer.
- The Git revision used to build the shipped binaries is recorded in
  BUILD-INFO.txt next to the installer.
